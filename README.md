# MedConnect

MedConnect é uma plataforma construída na Salesforce Platform para gerenciamento de eventos médicos, workshops, palestras, localizações, inscrições de participantes e sessões com especialistas.

## Funcionalidades principais

* Cadastro e login de usuários via Experience Cloud.
* Registro de participantes e organizadores.
* Controle de permissões por tipo de usuário usando Permission Sets.
* Listagem de eventos médicos.
* Visualização de detalhes de eventos.
* Inscrição de participantes em eventos.
* Painel administrativo para organizadores.
* Cadastro de eventos, localizações e palestrantes.
* Vinculação de palestrantes a eventos.
* Página de perfil do participante.
* Recuperação de senha.
* Interface responsiva para desktop, tablet e celular.

## Tecnologias utilizadas

* Salesforce Platform
* Apex
* Lightning Web Components
* Experience Cloud
* Salesforce DX
* Permission Sets
* Custom Objects
* Static Resources

## Principais objetos customizados

* Medical_Event__c
* Event_Attendee__c
* Event_Speaker__c
* Speaker__c
* Location__c
* Clinic_Organizer__c
